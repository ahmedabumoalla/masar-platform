# مسار — لكل قطرة ماء مسار

منصة عربية تفاعلية للتعريف بجهاز مسار واستكشاف مكوّناته ومحاكاة اكتشاف التسريب في مزرعة ثلاثية الأبعاد

## التشغيل

يتطلب Node.js 20.19 أو أحدث ضمن الإصدارات التي تدعمها Vite

```sh
npm install
npm run dev -- --port 5188
```

افتح `http://127.0.0.1:5188` محليًا

```sh
npm run build
npm run preview -- --port 5188
npm test
```

## الصفحات

- `/` هوية مسار الأصلية ومجسّم الجهاز وأطلس المملكة التفاعلي بمصادر المياه والمحاصيل ونوافذ تفاصيل المواقع
- `/device` الجهاز كاملًا أو مفككًا إلى ثماني مجموعات مع شرح كل مكوّن
- `/simulation` مزرعة بثلاثة قطاعات وستة حساسات ومقارنة قراءات التدفق

في المحاكاة اختر قطاعًا واضغط **إحداث تسريب** وتابع تغيّر الضغط والتدفق ثم تحديد الفرع المتضرر خلال ثلاث ثوانٍ محاكاة ويمكنك عزله وإصلاحه وإيقاف المضخة وتغيير السرعة أو إعادة التجربة

وضع **كشف الأنابيب** يكشف خط الري المدفون ويُفعّل عند إحداث تسريب فيه كما تتوفر كاميرا علوية وأزرار للتقريب والتحكم بلوحة المفاتيح

## ملفات Blender

- `assets/blender/masar-device.blend` نموذج الجهاز الأصلي القابل للتعديل
- `assets/blender/masar-farm.blend` نموذج المزرعة القابل للتعديل
- `scripts/build_device.py` و`scripts/build_farm.py` لإعادة بناء الأصول باستخدام Blender 4.5
- `public/models/` الأصول المصدرة للويب بصيغة GLB

```sh
blender --background --python scripts/build_device.py
blender --background --python scripts/build_farm.py
```

انظر `docs/device-model.md` و`docs/farm-model.md` لأسماء الطبقات وإحداثيات التركيب

## حدود النموذج ومصادره

الشعاران الأصليان استُخرجا من ملف مسار المرفق دون إعادة رسمهما واستُخدمت هوية الكحلي والأزرق والشعار النصّي كما وردت فيه

الجهاز إعادة بناء بصري للصورة والتفكيك في الصفحة السادسة ولا تتوافر أبعاد تصنيع أو مواصفات معايرة في المرجع والمحاكاة نموذج تعليمي يعتمد مقارنة تدفق الدخول والخروج لتحديد **الفرع بين الحساسات** وليست تحديدًا هندسيًا دقيقًا لموقع شق داخل أنبوب ولا اتصالًا بأجهزة حقيقية أو نموذج ذكاء اصطناعي مدرب

المرجع البصري لتنظيم التجربة: https://optivio-6isx.vercel.app/ مع تنفيذ خاص بمسار وأصول مبنية محليًا

لا توجد حسابات أو مفاتيح API أو خدمات خلفية ولا يرسل التطبيق ملف PDF أو قراءات إلى طرف خارجي والخطوط والأصول مستضافة محليًا ضمن التطبيق

## النشر

مخرجات البناء في `dist/` ويمكن نشرها على استضافة ثابتة تدعم إعادة كتابة مسارات التطبيق إلى `index.html` وأُضيف إعداد Vercel في `vercel.json` ولم يُنفذ نشر عام ضمن هذه المهمة

تفاصيل التحقق والقيود موثقة في `docs/task-state.md`
