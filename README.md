# Masar Platform

منصة مسار الزراعية الذكية لإدارة الري، اكتشاف الأعطال، طلب الخدمات الميدانية، الاستشارات، والسوق الزراعي.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## أوامر الفحص

```bash
npm run typecheck
npm run build
```

> تم تعديل أمر `npm run lint` مؤقتًا ليعمل كفحص TypeScript بدل أمر `next lint` لأنه كان يفتح إعداد ESLint التفاعلي ويفشل في النسخة السابقة.

## الرفع على Vercel

المشروع جاهز للرفع مباشرة على Vercel بعد رفعه على GitHub.

## المنتجات الحالية

- وحدة تحكم الري الذكي Masar Control X2
- مستشعر رطوبة التربة Soil Sense Pro
- حزمة ري بالتنقيط للمزارع الصغيرة Masar Drip Kit
- عداد تدفق ذكي Flow Track
- صمام كهربائي للتحكم بالقطاعات Sector Valve
- مغذيات زراعية متوازنة للنمو Balanced Grow

## آخر إصلاحات النسخة

- إضافة صفحة تفاصيل منتج لكل منتج في السوق `/market/[slug]`.
- إضافة ملفات `public` خفيفة حتى لا تظهر الصور مكسورة.
- إصلاح قراءة السلة من `localStorage` حتى لا يتعطل الموقع إذا كانت البيانات تالفة.
- تفعيل قائمة الجوال في الهيدر.
- إزالة تكرار ملف إعدادات Next والاكتفاء بـ `next.config.ts`.
